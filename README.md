# Foqi

Foqi is an open-source, minimalistic focus dock and physical lockout enclosure designed to eliminate doomscrolling and reclaim intentional device usage.

## Problem Statement

Modern smartphone addiction is heavily sustained by low-friction impulse access. Digital blockers alone often fail because they can be bypassed with a single tap in Settings. Physical friction creates the psychological barrier needed to disrupt unconscious doomscrolling loops.

Foqi physically locks the phone in an upright desk enclosure while preserving screen visibility for critical notifications and integrating a dedicated NFC slot for automation tools like [Foqos](https://foqos.co).

## Design Objectives

1. **Physical Lockout**: Prevent physical touch interaction with the capacitive touchscreen.
2. **Notification Transparency**: Slotted front face to keep the lock screen, clock, and emergency notifications visible.
3. **Hardware Automation**: Form-fitting NFC card slot (CR80 standard) directly aligned with the device's NFC antenna for automated session logging.
4. **Desktop Utility**: Clean upright desk geometry with integrated charger pass-through.
5. **Printability**: 100% support-free FDM 3D printing with parametric OpenSCAD geometry.

## Target Specifications

- **Device**: iPhone 13 in a standard protective case
- **Clearance Cavity**: 82 mm (W) x 16 mm (D) x 155 mm (H)
- **NFC Standard**: CR80 (85.6 mm x 54 mm x 1.0 mm)
- **Wall Thickness**: 3.0 mm (structural rigidity)
